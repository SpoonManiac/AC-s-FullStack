O modelo Client-Server (Cliente-Servidor) é uma arquitetura onde duas partes, o cliente e o servidor, interagem.

O Cliente é o usuário ou dispositivo que solicita dados ou realiza uma ação no servidor.

Já o Servidor hospeda os arquivos, gerencia os dados e processa as solicitações, enviando de volta as respostas ao cliente.

Padrão de Design MVC (Model-View-Controller)

O Model-View-Controller (MVC) é um padrão de design de software que divide a aplicação em três componentes principais:

O Model funciona como um gerente de loja, sendo responsável por gerenciar o acesso e a manipulação dos dados no banco de dados.

A View é a camada de apresentação, ou seja, exibe as informações ao usuário, como imagens e textos. Ela não lida com a lógica de negócios, apenas com a interface.

O Controller é o controlador da aplicação. Ele recebe as entradas do usuário através da View, processa essas informações e, se necessário, aciona o Model para atualizar os dados no banco de dados, controlando o fluxo da aplicação.
